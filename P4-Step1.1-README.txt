Rasadyar P4-Step1.1 — Optional Second Evidence Hotfix

هدف:
شاهد دوم برای ارسال پرونده به بررسی نهایی اختیاری باشد.

فایل کامل جایگزین:
src/features/analysis/caseReadiness.ts

قانون جدید:
- 0 شاهد = مانع سخت
- 1 شاهد = هشدار، نه مانع
- 2 شاهد = مناسب
- 3 شاهد یا بیشتر = وضعیت قوی

با یک شاهد:
- پرونده می‌تواند به بررسی نهایی برسد اگر سایر شروط آمادگی تکمیل باشند.
- شاهد دوم برای تأیید متقاطع توصیه می‌شود، اما الزامی نیست.
- تنوع منبع همچنان Warning باقی می‌ماند.
- Conflict Review با یک شاهد N/A است و مانع نمی‌شود.

کنترل‌های دیگر بدون تغییر:
- کامل‌بودن تحلیل ساختاریافته
- Machine Draft freshness
- Human Review
- Evidence Traceability
- Analysis Quality
- Conflict Review برای 2+ شاهد
- Revision / Audit Trail
- امتیاز کلی Readiness

Build:
npm.cmd run build

Run:
npm.cmd run dev

تست:
1) یک Case با دقیقاً یک Evidence باز کن.
2) سایر شروط لازم را تکمیل کن.
3) کارت «کفایت شواهد» باید Warning باشد نه Blocker.
4) پیام «حداقل دو شاهد لازم است» دیگر نباید نمایش داده شود.
5) اگر سایر Blockerها رفع شده و امتیاز آمادگی کافی باشد، «ارسال برای بررسی» باید انجام شود.
