نسخه فارسی World Monitor

تغییرات این نسخه فقط در لایه نمایش و بومی‌سازی انجام شده است:
- فارسی به‌عنوان زبان پیش‌فرض رابط
- تکمیل ترجمه رابط اصلی و پنل‌های داشبورد
- راست‌چین (RTL)
- فارسی‌سازی صفحه بارگذاری اولیه
- نمایش تاریخ با تقویم هجری شمسی
- نمایش زمان بر اساس منطقه زمانی Asia/Tehran
- اضافه‌شدن تهران به ساعت جهانی و استفاده از ساعت ایران به‌عنوان مرجع نمایش

منطق دریافت داده، APIها، محاسبات، نقشه، مدل داده و سرویس‌های اصلی پروژه تغییر نکرده‌اند.

اجرای محلی در Windows PowerShell:
1) وارد همین پوشه شوید (package.json باید همین‌جا باشد)
2) npm.cmd install
3) npm.cmd run dev
