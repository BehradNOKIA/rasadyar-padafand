Rasadyar P4-Step1.2 — Relaxed Review Gate

هدف:
«ارسال برای بررسی» نباید فقط برای پرونده تقریباً کامل ممکن باشد.
بررسی، خودش مرحله‌ای برای تکمیل تحلیل و کنترل کیفیت است.

فایل کامل جایگزین:
src/features/analysis/AnalysisCenter.tsx

قانون جدید ارسال برای بررسی:
- عنوان لازم است.
- شرح مسئله لازم است.
- حداقل 1 شاهد لازم است.
- شاهد دوم اختیاری است.
- امتیاز Readiness مانع ارسال نیست.
- Traceability ناقص مانع ارسال نیست.
- Quality پایین مانع ارسال نیست.
- Conflict Review ناقص مانع ارسال نیست.
- Machine Draft قدیمی مانع ارسال نیست.
- Human Review ناقص مانع ارسال نیست.

تمام موارد بالا همچنان در داشبوردهای P3 نمایش داده می‌شوند و برای تصمیم تحلیلگر/مدیر حفظ شده‌اند، اما در مرحله «ارسال برای بررسی» فقط نقش راهنما دارند.

اگر پرونده هنوز آماده نهایی نباشد، پس از ارسال پیام مشابه زیر نمایش داده می‌شود:
«تحلیل برای بررسی ارسال شد؛ امتیاز آمادگی فعلی X/100 است. موارد تکمیلی صرفاً به‌صورت راهنما در داشبورد آمادگی نمایش داده می‌شوند.»

نکته:
این Hotfix با P4-Step1.1 سازگار است.
P4-Step1.1 فقط caseReadiness.ts را تغییر داده بود و این بسته فقط AnalysisCenter.tsx را تغییر می‌دهد.

Build:
npm.cmd run build

Run:
npm.cmd run dev

تست:
1) همان پرونده یک‌شاهده را باز کن.
2) عنوان و شرح مسئله داشته باشد.
3) «ارسال برای بررسی» را بزن.
4) حتی اگر Readiness زیر 80 باشد، باید ارسال شود.
5) وضعیت پرونده باید «در حال بررسی» شود.
6) داشبورد آمادگی همچنان امتیاز/هشدارها را نمایش دهد.
7) پرونده بدون هیچ شاهد همچنان نباید برای بررسی ارسال شود.
